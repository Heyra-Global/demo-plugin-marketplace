# Email examples (Heyra house style)

Loaded on demand from the email-style skill.

## Reply to a colleague asking for a decision

```
Emne: [Beslutning] Skrabelykke påske - trykoplag

Hej Sofie

Vi går med 180.000 kort. Det er 10 % over sidste års salg og inden for
budgettet.

To ting, før vi bestiller:
- Trykkeriet skal bekræfte levering senest 14. marts.
- Compliance skal godkende bagsideteksten (den nye ROFUS-formulering).

Jeg sender bestillingen torsdag, hvis begge er på plads. Sig til, hvis du
ser noget, jeg mangler.

Vh
Anders
```

## A self-exclusion request lands in a personal inbox (same day, no marketing)

```
Til: ansvarligtspil@heyra.example
Emne: HASTER: anmodning om udelukkelse - videresendt

Hej Ansvarligt Spil
Videresendt straks. Afsender beder om at blive udelukket. Jeg har kun
bekræftet modtagelse og ikke skrevet andet.
Vh Anders
```

Reply to the sender:

```
Hej

Tak for din besked. Jeg har sendt den videre til vores team for ansvarligt
spil, som kontakter dig i dag. Du kan også udelukke dig selv med det samme
via ROFUS på spillemyndigheden.dk.

Venlig hilsen
Anders Lund
Heyra
```

## English reply to a supplier

```
Subject: Re: Q4 media plan - revised rates

Hi Priya

Thanks for the revised rates. We can accept the outdoor package at the new
price. We cannot accept the TV slots as planned: Danish rules will soon ban
gambling ads around live sport, so we need the Sunday slots moved outside
the match windows.

Could you send a revised TV schedule by Friday 20 September? Then I can
confirm the whole plan the same day.

Kind regards
Anders Lund
Marketing & Communications, Heyra
```

```
Hej Mette

Kort påmindelse: jeg mangler din godkendelse af pressemeddelelsen inden kl.
15, så den kan sendes i dag. Hvis du ikke har indvendinger, svarer du bare
"ok".

Vh
Anders
```
