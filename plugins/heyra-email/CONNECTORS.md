# Connectors

Skills refer to tools by category, written as `~~category`.

| Category | Placeholder   | Pre-configured for Heyra          | Other options |
| -------- | ------------- | --------------------------------- | ------------- |
| Email    | `~~email`     | Microsoft 365 (Outlook mail)      | Gmail         |
| Calendar | `~~calendar`  | Microsoft 365 (Outlook calendar)  | Google Calendar |
| Contacts | `~~contacts`  | Microsoft 365 (people)            |               |

Microsoft 365 is a built-in Claude connector. Turn it on under **Customize >
Connectors** in Claude Chat or Cowork and grant mail and calendar access.

Without a connector, paste the email or the thread into the chat. Every
skill accepts pasted text.

## What the skills never do

- Send an email. They draft; you send.
- Delete or move mail without asking first.
- Put player data, national ID numbers or account details into a draft.
